# Use cases

Choose a scenario after completing the [first synthetic run](../getting_started/first-run.md). Scenario READMEs in the repository own their launch and analysis commands; this catalog does not duplicate them.

| Scenario | Purpose and prerequisites | Instructions and evidence |
|---|---|---|
| Robot fight | Multi-UE movement, interference and application outcomes; requires its configured radio workspace | [Scenario](../../use_cases/robot_fight/README.md), [R7 experiment](../reports/experiments/robot-fight-r7/README.md) |
| Scheduler benchmark | Compare scheduling behavior under the declared workload and channel; requires the matching stack setup | [Scenario](../../use_cases/scheduler_benchmark/README.md) |
| CMX500/X310 | Instrument/USRP experiments; requires the physical equipment, UHD and stated timing setup | [Scenario](../../use_cases/cmx500/README.md), [original feasibility design](../development/designs/cmx500-x310-srsue-feasibility.md) |
| Shared topologies and scenes | Synthetic, live-stack, multi-port and Sionna inputs | [Configuration catalog](../../use_cases/configs/README.md), [configuration reference](../reference/configuration.md) |

Hardware and live-connectivity claims apply only to their recorded setup. Review [current limits](../getting_started/status.md) before selecting a scenario for a qualification claim.
