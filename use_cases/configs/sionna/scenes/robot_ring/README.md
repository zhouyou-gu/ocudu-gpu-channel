# robot_ring — the robot-fight arena scene

Generated by `build_robot_ring.py` (plain Python, no Sionna). Used by
`use_cases/configs/sionna/scenarios/robot_ring/robot-ring.json` and the R track in
[`ROBOT_FIGHT_MILESTONES.md`](../../../../../ROBOT_FIGHT_MILESTONES.md).

```
python3 build_robot_ring.py          # regenerate scene.xml + meshes/ + manifest.json
```

| Object | Geometry | Material |
| --- | --- | --- |
| `ground` | 60 × 60 m slab at z = 0, ring centre at the origin | concrete |
| `fence` | annulus r = 4.0–4.1 m, 0.3 m high, 48 segments | metal |
| `building_pillar_{0,1,2}` | 0.8 × 0.8 × 3 m boxes at (0, −1.6), (0, 0), (0, 1.6) | concrete |
| `building_mast` | 0.2 × 0.2 × 7.5 m at (15, 0); the gNB antenna is at (15, 0, 8), 0.5 m clear of the top — a source placed on a mesh face traces no paths at all | metal |

The gNB looks west across the ring. The pillars sit on the ring's centre
line, so the eastern half (+x) is LOS and the western half (−x) is a picket
of NLOS pockets behind each pillar with LOS gaps between them. Robot UEs
carry their antenna at 0.4 m, above the fence, so the fence only reflects.

The mast is 15 m out rather than "just outside the ring" on purpose: with the
bridge's default `--gain-offset-db 60`, a 10–20 m LOS path lands the
strongest tap at about −10…0 dB, inside the range the srsUE gates already
run at (legacy fixture −3 dB, Sionna canyon −13 dB). A mast at the fence
would push the taps past 0 dB.

`coverage_grid.py` traces a UE over a grid across the ring exactly as the
bridge does and prints/plots the strongest downlink tap gain, which is how
the LOS/NLOS asymmetry in the milestone record was measured.
